# CODE 指令执行覆盖记录

BIN_INSPECTOR 的 `INSTRUCTION_COVERAGE` 面板可开启记录、关闭记录或清除。默认关闭；开启后，摘要显示成功指令总次数和执行过的不同指令起始地址数，反汇编行显示该起始地址最近采样的执行次数。

这里只记录 **真实成功执行的指令起始 CODE 地址**，不是字节覆盖、源码覆盖或分支覆盖率，不提供没有可靠分母的百分比。多字节指令只记起始地址，操作数字节不随之标为覆盖；若程序确实跳入某个操作数字节并从那里成功执行，该地址才独立计入。

- 单步、运行、Step Over/Out 内成功完成的指令都计数，CALL、RET、RETI 也按各自起点计数。
- idle、掉电等待、中断响应单元不计数；中断处理程序里实际执行的指令计数。
- 指令故障不计入失败的那条，已成功完成的记录保留。
- 取指前断点/条件错误停止不计入尚未执行的指令；内存变化观察点在执行后停止，因此引起变化的成功指令计入。
- ReadMemory、Watch、覆盖查询、修改寄存器/内存都不会产生执行记录。

## 生命周期

| 操作 | 记录 | 开关 |
| --- | --- | --- |
| 初次打开 / 刷新 | 空 | 关闭 |
| 关闭记录 | 保留 | 关闭 |
| 再次开启 | 从保留值继续累加 | 开启 |
| 清除 | 清零；CPU 和当前运行继续 | 保留 |
| CPU 复位 | 清零 | 保留 |
| 成功加载/替换固件或恢复工作区 | 清零 | 关闭 |
| 暂停、导航、编辑 PC/寄存器/内存 | 保留 | 保留 |
| 无效加载/恢复被拒绝 | 保留 | 保留 |

运行中的开关和清除在 Worker 消息边界生效，不取消运行。记录和开关均为当前会话状态，不写入工作区 v4 或 CPU 快照 v2；刷新不能恢复统计。单地址计数以 `2^32−1` 饱和，总次数以安全整数上限饱和，不会回绕为零；界面会标注达到上限。

## 采样和开销

默认关闭时不分配计数表，也不在运行循环内发送覆盖消息；成功执行路径仅多一次开关判断。开启时 Worker 分配 256 KiB 的 65536 项计数表，每条成功指令 O(1) 更新，不复制 CPU 快照。

前端只查询当前反汇编显示的 80 个指令起始地址；常规查询单次最多接受 256 个地址，不传输全表；显式报告请求是下述例外。运行中每 250ms 查询，导航/暂停后更新当前行；离开 BIN_INSPECTOR 停止轮询。计数是最近一次采样，等待期间显示省略号；清除、模式变化和换固件使用代次和最新请求编号排除过期结果。换固件等待期间立即撤下旧记录，避免将旧次数标到新代码。

可复现基准：`node scripts/benchmark-coverage.mjs e57399d`。它用实际 Worker 线程和同一 CPU 核心，对比旧 Worker 入口、当前默认关闭、开启记录、开启并每 250ms 查询 80 个地址。每种预热 30000 条，再执行 200000 条，交替顺序测 5 轮；输出中位时间、覆盖消息数和 JSON 体积估算（不是浏览器实际传输字节数）。这是本环境的微基准，不是跨机器性能保证；结果记录在路线图。

## 固定报告与热点导航

点击“采样热点”生成固定报告；“导出覆盖报告”重新采样并下载 `.coverage.json`，不是把旧列表当成当前记录。两者均允许在运行中使用，不暂停 CPU；同一时间只处理一个界面请求。前 20 个热点按次数降序、同次数按地址升序排列。点击地址固定反汇编浏览位置、丢弃未确认地址草稿并聚焦地址输入；支持返回历史和跟随 PC，不修改 PC、断点或运行目标。报告明确标为固定采样，执行继续时不会自动更新。

JSON v1 包含：

- `format: "emuc51-instruction-coverage"`、`scope: "successful-instruction-starts"`；
- `firmware.name / sha256 / byteLength`：Worker 实际接受的固件字节，SHA-256 由 Worker 独立计算。HEX 使用解析后的二进制内容，不是 HEX 文本；不包含 CODE 尾部隐式补零；
- `capturedAt`：采样时的浏览器墙钟；`pc / steps`：同一边界的 CPU 状态，steps 含非指令执行单元，不能直接当成记录条数；
- `summary`：开关、代次 epoch、总成功指令数、唯一地址数、饱和标识；epoch 仅在当前 Worker 生命周期内可比较，不是跨会话全局编号；
- `entries`：全部非零 `{address, count}`，地址升序，最多 65536 项；地址/次数为十进制 JSON 数字。地址覆盖 CODE 全空间，可包括固件尾部之后实际执行过的隐式 NOP。计数达到 `4294967295` 时应按下界理解；总次数饱和或地址计数饱和后不得根据求和推导精确次数。

Worker 在执行批次间同步复制全部摘要、状态和非零计数，然后异步计算并缓存固件摘要；后续执行不会改变已捕获数据。仅显式生成报告时扫描 64Ki 地址空间，不增加每条指令或周期轮询的传输量。固件加载时保留一份最多 64 KiB 的不可变原始字节，用于验证身份。

清除、复位、开关变化及成功加载/恢复会撤下报告；异步摘要完成时再检查固件身份和代次。前端同时检查请求编号、代次及固件摘要，已取消的请求不能下载或显示旧报告。SHA-256 失败会展示错误并允许重试。无效固件或恢复请求不破坏已有统计。报告不含内存快照，不写入工作区；导出文件也不能作为工作区导入。下载后已保存的历史报告不会随页面清除而删除。
