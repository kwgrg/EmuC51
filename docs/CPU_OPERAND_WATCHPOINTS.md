# CPU 字节操作数访问观察点

在调试面板选择空间、读/写/读写和十六进制单字节地址，再添加观察点。每次最多 128 项，重复项不可添加，Escape 恢复地址草稿；运行中不可修改。配置随工作区 v4 保存，CPU 快照仍为 v2，旧工作区缺省为无访问观察点。

| 空间 | 已支持范围 | 示例 |
| --- | --- | --- |
| DATA | 直接寻址 00–7F | `MOV 20h,A` |
| IDATA | `@R0/@R1` 间接寻址 00–7F | `MOV A,@R0` |
| XDATA | MOVX，0000–FFFF | `MOVX @DPTR,A` |
| SFR | 经典 8051 已定义的直接字节地址 | `MOV A,P1` |

DATA 和 IDATA 共享 128 字节物理 RAM，但按寻址方式匹配；不支持 8052 高 128 字节。PUSH/POP 的直接操作数被记录，隐式栈存取不记录。

事件来自指令操作数执行路径，保留指令起始 PC、空间、地址、读写类型和实际字节值。同值写入也触发，读改写按“读→写”记录；同一指令多个匹配访问全部按顺序显示，重叠观察点不会复制事件。端口普通读取返回引脚值，读改写返回锁存值；SBUF 使用现有外设读写语义。访问发生后完成整条指令及其外设推进，再暂停，因此当前 PC 可能是下一指令或分支目标，不等于事件 PC。

连续运行、单步、步过、跳出、运行至地址均共用此机制。取指前地址断点仍先于该指令执行；访问命中在指令完成后优先于旧值变化观察点及运行至地址完成。故障不提交本条访问事件；idle、中断进入、复位、恢复和下一执行单元会清除旧事件。暂停恢复不回滚已完成指令。

这是限定的字节操作数功能，不是完整 CPU 总线探针。位操作、Rn/隐式 A/标志/DPTR/SP、隐式调用/返回/中断栈、取指和 MOVC 的 CODE 访问均不记录。UI/表达式读取、暂停编辑、操作数验证、奇偶位维护、定时器/UART/GPIO 内部更新不触发。显式 `MOV A,ACC` 中的直接 ACC 源操作数仍会记录。旧“写入监视点”继续比较执行前后字节值，包含外设更新，语义与本功能独立。

验证：`tests/core/operand-access.test.ts` 检查空间隔离、RMW、同值写入、端口/SBUF、PUSH/POP 和所有 255 条合法编码开启/关闭观察后的状态一致性；Worker 验证执行控制、配置替换原子性与恢复；持久化和 Chromium E2E 验证刷新、JSON 往返、重复/取消、地址边界、运行时锁定及手机布局。
