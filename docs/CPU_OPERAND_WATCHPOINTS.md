# CPU 字节与位操作数访问观察点

在调试面板选择空间、读/写/读写和十六进制字节地址或 BIT 位地址，再添加观察点。每次最多 128 项，重复项不可添加，Escape 恢复地址草稿；运行中不可修改。配置随工作区 v4 保存，CPU 快照仍为 v2，旧工作区缺省为无访问观察点。

| 空间 | 已支持范围 | 示例 |
| --- | --- | --- |
| DATA | 直接寻址 00–7F | `MOV 20h,A` |
| IDATA | `@R0/@R1` 间接寻址 00–7F | `MOV A,@R0` |
| XDATA | MOVX，0000–FFFF | `MOVX @DPTR,A` |
| SFR | 经典 8051 已定义的直接字节地址 | `MOV A,P1` |
| BIT | 00–7F：DATA 20–2F；80–FF：经典可位寻址 SFR | `CPL P1.0` |

DATA 和 IDATA 共享 128 字节物理 RAM，但按寻址方式匹配；不支持 8052 高 128 字节。PUSH/POP 的直接操作数被记录，隐式栈存取不记录。

事件来自指令操作数执行路径，保留指令起始 PC、空间、地址、读写类型和实际字节值或位值（0/1）。同值写入也触发，读改写按“读→写”记录；同一指令多个匹配访问全部按顺序显示，重叠观察点不会复制事件。端口普通读取返回引脚值，读改写返回锁存值；SBUF 使用现有外设读写语义。访问发生后完成整条指令及其外设推进，再暂停，因此当前 PC 可能是下一指令或分支目标，不等于事件 PC。

连续运行、单步、步过、跳出、运行至地址均共用此机制。取指前地址断点仍先于该指令执行；访问命中在指令完成后优先于旧值变化观察点及运行至地址完成。故障不提交本条访问事件；idle、中断进入、复位、恢复和下一执行单元会清除旧事件。暂停恢复不回滚已完成指令。

这是限定的显式操作数功能，不是完整 CPU 总线探针。Rn/隐式 A/标志/DPTR/SP、隐式调用/返回/中断栈、取指和 MOVC 的 CODE 访问均不记录。UI/表达式读取、暂停编辑、操作数验证、奇偶位维护、定时器/UART/GPIO 内部更新不触发。显式 `MOV A,ACC` 中的直接 ACC 源操作数仍会记录。旧“写入监视点”继续比较执行前后字节值，包含外设更新，语义与本功能独立。

验证：`tests/core/operand-access.test.ts` 检查空间隔离、RMW、同值写入、端口/SBUF、PUSH/POP 和所有 255 条合法编码开启/关闭观察后的状态一致性；Worker 验证执行控制、配置替换原子性与恢复；持久化和 Chromium E2E 验证刷新、JSON 往返、重复/取消、地址边界、运行时锁定及手机布局。

## 位地址和事件语义

选择 BIT 后输入的是 **8051 位地址**，不是所属字节地址：00 对应 DATA 20.0，7F 对应 DATA 2F.7，90 对应 SFR 90.0，D7 对应 PSW 的 CY 位。公式：低位地址的字节为 `20h + (地址 >> 3)`；高位地址的字节为 `地址 & F8h`；位序为 `地址 & 7`。共享 Memory8051 的经典 SFR 校验，C0、F8 等未定义 SFR 位地址以及超出 00–FF 的输入均拒绝。保留位采用现有核心的整个位可寻址 SFR 模型，不新增衍生器件行为。

BIT 事件附带所属 DATA/SFR 字节地址、位序，以及读取来源（引脚、锁存器或存储位）。它与 DATA/SFR 字节观察点分别匹配：字节写入即使改变目标位，也不触发 BIT；位指令的底层字节读写不会伪装成显式字节访问。因此现有工作区和字节观察点行为保持兼容。工作区仍为 v4，配置只新增 `space: "bit"` 可选值；旧记录无需转换，缺少观察点时仍为空。早期应用不识别 BIT，新记录应在本版本或更新版本恢复。

| 位操作 | 记录 |
| --- | --- |
| JB、JNB、MOV C,bit、ANL/ORL C,bit（含 /bit） | 读取目标位；端口来自输入引脚；/bit 记录取反前的实际位值；进位逻辑不会跳过操作数读取 |
| CPL bit | 读→写；端口读取输出锁存器 |
| JBC bit,rel | 读；仅位为 1 时追加清零写；端口读取锁存器；分支后的 PC 与事件起始 PC 分别保留 |
| CLR bit、SETB bit、MOV bit,C | 写；即使写入相同值也记录；保留同字节其他位时的内部锁存器读取不单独生成读事件 |

本功能追踪架构显式操作数而非每个硬件总线周期。CLR/SETB/MOV bit,C 内部保留其他位所需的读不意味着显式读取目标位；CPL/JBC 的目标位读取则真实记录。`CLR C`、`SETB C`、`CPL C`、运算导致的 CY/AC/OV/P 更新及 UI 读取不触发 BIT。使用编码含位地址的显式 `MOV C,PSW.0`、`CPL PSW.7` 则触发，额外的隐式 flags 维护不复制事件。

语义依据：[Atmel 8051 指令手册](https://www.keil.com/dd/docs/datashts/atmel/at_c51ism.pdf)，特别是 CPL 和 JBC 的端口锁存器注释及 JBC 位为零时不清零的说明；没有引入硬件总线精度声明。

位扩展验证：`tests/core/bit-access.test.ts` 覆盖 12 种含位地址的指令编码、216 个经典合法位地址、全部非法范围、分支/同值写、低引脚与高锁存器、逻辑非短路和隐式更新排除；Worker、JSON 往返和 Chromium 覆盖执行控制、刷新、配置校验/取消、端口输入和字节兼容。
