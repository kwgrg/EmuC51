# 当前核心能力与剩余阻塞

## 已完成的本地开发闭环

- 经典 8051 CPU、GPIO、Timer、UART、中断与快照；固件和源码不上传。
- 单文件 ASM 编辑、构建、诊断、加载、源码映射和 CODE 标签导航。
- 外部固定版本 SDCC 构建导入；源码/IHX/CDB/实际固件摘要绑定、精确源码地址定位。
- 地址/条件/次数断点、观察点、只读 Watch、内存编辑和导航、执行覆盖报告。
- 真实 CALL/中断帧、可暂停且有预算的 Step Out；验证过的 CDB 函数入口名称，不伪造恢复历史。
- 有界 GPIO/UART 场景重放、工作区持久化和导入导出。
- SDCC 静态全局存储原始字节观察，身份与地址空间严格区分；不包含通用 C 类型、局部变量、解引用或 C 语句步进。

## 有限整数格式证据

[真实样本](../tests/fixtures/sdcc-integers/README.md)覆盖 8/16/32 位正负边界、unsigned 零/最大值、小端存储和多种未支持类型。`enum_value` 与普通 signed char 均为 `{1}SC:S`；`long long` 为 `{8}SI:S`，不能只看 SI 就当 16 位；`_Bool` 为 `{1}:S`。数组的 `DA`、指针的 `DG`、结构体的 `ST` 等类型链不能当标量。

额外证据的候选方案须先验证确实保留 enum 类型身份并覆盖头文件/typedef，再决定导入协议；手写名称白名单、源码正则或仅增加一个清单布尔值均不足以成为可信类型证明。
