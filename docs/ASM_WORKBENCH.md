# 本地单文件 ASM 工作台

实现版本 `emuc51-asm-1`。这是自有的、有界两遍汇编器，复用项目的经典 8051 操作码表；不是 KEIL A51、SDCC 的 sdas8051 或 C 编译器。无需安装、网络或后端。构建在独立浏览器 Worker 中执行。

## 使用与状态

1. 打开 BIN_INSPECTOR，点击“编辑 ASM 源码”滚动到工作台；“新建 ASM 示例”或导入 UTF-8 `.asm`。
2. 编辑后点击“构建 ASM”。错误显示真实行/列，点击诊断定位选区。失败不返回部分 BIN，也不保留可加载的旧构建按钮。
3. 成功后可导出 ASM/BIN，或显式“加载构建产物”。加载会复位 CPU，沿用固件加载流程。构建本身不改变 CPU。
4. 已加载 ASM 固件后，编辑、取消或失败重建会锁定运行、单步、步过、跳出和运行至地址。浏览内存/反汇编及复位仍可用。重新构建若源码 SHA-256、产物 SHA-256 与已加载绑定完全一致，可继续原 CPU；否则须显式加载新产物。仅修改注释也会改变源码摘要，不能无提示沿用旧关联。
5. 连续点击构建只启动一个 Worker；取消终止 Worker，旧响应不能恢复产物。编辑中断旧构建。运行/恢复期间源码只读，禁止启动构建或加载；暂停后可编辑。切换到内存或 I/O 页不丢草稿。

成功产物携带原始源码、源码 SHA-256、固件 SHA-256 和汇编器版本。加载前再次核验当前源码及实际字节摘要。导出 BIN 是裸固件，独立载入时不宣称与编辑器源码关联。明确替换外部 BIN/HEX 会解除原 ASM 绑定、撤销构建，但保留源码草稿并显示“当前固件独立于 ASM 草稿”。

## 保存和导入导出

- 单个草稿即时保存在本地 `localStorage`（`emuc51.asm-draft.v1`），没有固件时刷新也可恢复。存储失败显示错误，仍可导出 ASM。没有账号、上传或云保存。
- 已有固件时，工作区 v4 的可选 `settings.asmProject` 保存文件名/源码，`asmBinding` 保存已加载 ASM 的版本/摘要。CPU 快照仍为 v2。变更后的草稿允许与旧绑定并存，但执行锁定。
- 刷新或 JSON 恢复不信任历史构建对象：构建产物、诊断、Worker 均不持久化，必须重建核验后才能继续 ASM 调试；恢复保留 CPU 位置。非法绑定（如固件摘要不一致）拒绝显式导入，原工作区不变。
- 导入工作区以其 ASM 字段替换当前草稿；没有 ASM 字段的旧工作区清除当前草稿/绑定。导入源码只替换单个源文件，保留现有 CPU，但使旧 ASM 绑定过期。
- “导出 ASM”仅保存 UTF-8 文本；“导出 BIN”仅保存最新成功产物；“导出工作区”包含源码、关联、CPU 和调试设置。没有固件时用 ASM 导出备份。源文件名限制为 ASCII 字母/数字/下划线/点/短横线，不合规导入名使用 `main.asm`。
- CLEAR_LOCAL 同时删除工作区和 ASM 草稿，构建任务终止。关闭/刷新已有固件的工作区前应等待“已保存”；浏览器存储不替代文件备份。旧应用会忽略新增 ASM 字段，只能作固件调试，不支持此关联保护流程。

## 支持语法

| 类别 | 支持范围 |
| --- | --- |
| 指令 | 操作码表中的全部 255 个合法经典 8051 编码形式；助记符/寄存器/符号不区分大小写，操作数用逗号分隔。保留编码 A5 无指令助记符，可作为 DB 数据 |
| 标签 | `LOOP:`，可与指令同一行；ASCII 字母或下划线开头，后续字母/数字/下划线。指令和数据操作数允许前向引用；重复或保留名报错 |
| 整数 | 十进制、`0xFF`、`0FFh`、`1010b`。后缀十六进制须数字开头；不自动截断溢出或把 -1 转成 FF |
| 常量表达式 | 符号、SFR 名称、整数、`$`，一元 +/- 及二元 +/-；没有乘除、括号、字符串、函数、隐式类型转换。SFR 名称如 P1、ACC、PSW，位地址可写 `P1+1` 或数值，**不支持 P1.1 位名语法** |
| ORG | `ORG 已知地址`，0..FFFF，允许后退但不能重叠写入；间隙补零。布局必须第一遍确定，不接受前向符号 |
| EQU | `NAME EQU 已知表达式`，0..FFFF；不能重定义或前向/循环依赖，不带冒号 |
| DB / DW | 逗号分隔的数值表达式；DB 0..255，DW 0..65535，DW 大端。`$` 为当前数据项地址 |
| END / 注释 | 可选 `END` 无操作数，其后仅空行/注释；`;` 到行尾注释。支持 LF/CRLF/CR 换行和文件首 BOM |

指令内 `$` 是该指令起始地址。相对跳转按 16 位回绕后的下一指令地址计算，严格检查 -128..127；AJMP/ACALL 检查下一指令的 2 KiB 页。指令本身不能跨越 FFFF 编码，不自动选择短/长跳转。MOV direct,direct 正确使用“源字节在前”的机器码布局。

限制：最多 65536 UTF-16 字符、8192 行，导入文件最多 256 KiB，CODE 最多 64 KiB，最多返回 50 个诊断。全部错误修复前不产生 BIN。CPU 始终从 PC=0 加载；ORG 到非零地址不会设置入口点，需要自行在 0 安排跳转。无多文件链接、INCLUDE、宏、条件汇编、段/重定位系统、结构类型或 C 局部变量。SDCC 自动生成的汇编使用另一套方言，应交给真实 SDCC 工具链处理。

## 已验证样例

内置示例经汇编后为 `74 00 12 00 07 80 FB 04 F5 90 22`，包含 LCALL/RET、循环递增 A 和 P1 写入；CPU 单元测试验证两轮后 A/P1=2 且 SP 平衡。浏览器另外验证 `MOV A,#42h / MOV P1,A / SJMP $` 输出 `74 42 F5 90 80 FE`，导出摘要、实际载入及单步结果一致。

测试还覆盖全部合法编码的反汇编往返、独立黄金字节、边界跳转、地址重叠、未定义符号、诊断定位、CRLF、取消/旧响应、失败后的旧产物锁定、刷新、工作区切换与三个屏幕宽度。另有独立的[真实 SDCC 样例](../tests/fixtures/sdcc-counter/README.md)，不以自有汇编器模拟 SDCC。


## 真实源码调试

成功汇编会生成每个已编码语句的行、列、起始地址、长度和指令/数据类别。映射由第二遍实际编码产生，与同一 Worker 的源码/固件摘要一起传回；构建失败不发布部分映射。它不来自反汇编猜测，也不从外部 JSON 信任映射。

显式加载该 ASM 产物并验证与当前源码、固件和已加载绑定完全一致后，工作台显示源码调试列表。每页最多 100 行，PC 只高亮**精确指令起始地址**，可点击“定位当前 ASM 行”跳到所在页。纯标签、注释、EQU、ORG、END 不作为可执行行；DB/DW 显示数据起始地址，但不提供行断点/运行入口；ORG 补零空隙、指令操作数字节不推断行。标签与指令在同一行时映射到该指令。当前单文件无宏展开，一条指令行只有一个地址。

行断点共用既有地址配置，显示已启用/已禁用状态，保留条件和命中阈值。再次点击移除该地址断点；“查看”只改变反汇编浏览位置，支持既有历史；“运行至”在指令执行前停止，不添加永久断点，仍遵守预算、暂停及其他停止条件。运行期间禁止行断点/查看/运行操作，分页与定位 PC 仍可用。

编辑、失败/取消/重新构建、换固件或工作区会撤下旧映射入口。仅构建但未加载不关联当前 CPU；注释变化即使生成相同 BIN，也不能沿用旧源码摘要。刷新或导入工作区后必须重新构建匹配版本，再恢复映射，保留 CPU PC 和已有地址断点。映射及分页位置不持久化，CPU v2/工作区 v4 不变；离开工作台后分页重新从第一页开始。

验证包括混合换行/BOM、变长编码、FFFF 边界、反向 ORG、数据和空隙、失败无残留映射、Worker 摘要绑定、分页/运行锁定，以及实际浏览器的行断点、导航不改 PC、运行至行、预算、暂停、修改失效、刷新重建和移动端布局。不宣称 C 语句步进或源级局部变量支持。

## CODE 标签浏览

已增加真实冒号标签的定义定位、CODE 内存导航及指令起始地址断点。EQU/寄存器常量不作为 CODE 标签，别名共享地址断点，数据/操作数字节/ORG 空隙不伪装指令；详见 [绑定、来源与边界](VERIFIED_SYMBOLS.md)。
