# 只读 Watch 表达式

SYS_MEM 的 Watch 支持添加、删除和刷新表达式。列表在页面切换期间保留，浏览器刷新后清空；不写入工作区 v3 或 CPU 快照 v2。

- 十进制及 `0x` 十六进制整数；名称不区分大小写。
- `PC`、`DPTR`、`A` / `ACC`、经典 SFR 名称，以及当前 PSW 寄存器组的 `R0`–`R7`。
- `IRAM[0..127]`、`SFR[0x80..0xFF]`（仅已定义 SFR）、`XRAM[0..65535]`、`CODE[0..65535]`。地址不回绕，不支持 8052 上半区 IRAM。
- 括号、一元 `+ - ~`，二元优先级从低到高：`|`、`^`、`&`、`<< >>`、`+ -`、`* / %`；同级从左向右。
- 算术使用安全整数（绝对值不超过 9007199254740991），溢出报错；除法向零截断。位运算先转 32 位，结果按无符号显示；右移为逻辑右移，位数限 0–31。除零和取余零报错。

例如 `XRAM[DPTR] + ACC`、`IRAM[SP]`、`(PSW >> 3) & 3`、`CODE[PC]`。本语法是独立的有限子集，不宣称兼容完整 KEIL/C 表达式，不支持源码变量、函数调用、赋值、指针或类型转换。

最多 32 项，每项 256 字符、128 词元、解析递归 16 层；超限或非法语法逐行报错，不影响其他行。使用自定义解析器，不执行 JavaScript。

Worker 在单次消息内采样整批表达式，并返回采样 PC 和已执行指令数。暂停、单步、编辑、导航至 SYS_MEM 时自动刷新，运行时随状态通知刷新，也可手动刷新；它不是每条指令的历史跟踪。UI 只接受最新请求的结果，固件切换和列表修改会作废旧结果。

读取不会执行指令或触发变化观察点。SFR（含端口和 SBUF）统一读取锁存值，不调用外设读取钩子；端口引脚状态仍在 GPIO 面板查看，SBUF 不表示串口待接收队列。观察操作不确认中断、不消耗串口数据、不改变 CPU 快照。
