# 经典 8051 外设核对：UART TI 时点

基线：`f101bb3`，2026-10-11。范围为现有经典 8051/AT89C51 模型：128B IRAM、12 振荡周期/机器周期、T0/T1、五个中断向量、两级优先级与数字 UART/GPIO。不是完整 AT89C51 芯片仿真；CODE/XDATA 空间沿用项目模型，不模拟 Flash、电气特性或总线波形。

依据为制造商原始资料：[AT89C51 数据手册](https://www.keil.com/dd/docs/datashts/atmel/at89c51_ds.pdf) 的器件范围、idle/power-down 说明，以及 [Atmel 8051 Hardware Manual 4316E](https://ww1.microchip.com/downloads/en/DeviceDoc/doc4316.pdf) 的 Timer0/1、SCON、Interrupts 章节。后者包含增强器件功能，本次只使用经典子集；Timer2、X2、自动地址识别、FE/SMOD0、独立波特率发生器均不引入。Keil 仅作为部分原始 PDF 的托管站点，不以其仿真界面作为硬件规范。

## 核对范围与结论

| 范围 | 现有实现/验证 | 本轮处理 |
| --- | --- | --- |
| T0/T1 模式 0/1/2、溢出、门控、计数 | 13/16 位、自动重装、TF 粘滞、TR/GATE 和负边沿；原测试涵盖基本行为 | 增补两定时器三模式的门控关闭忽略边沿、有效下降沿溢出及持续低电平不重复计数 |
| 模式 3 | TL0/TH0 分拆、TR1/TF1 归 TH0，T1 模式 3 停止；T1 可在 T0 分拆时供 UART 使用 | 增补无 TR1、无 TF1 的串口 TI 边界验证，未改变器件模型 |
| GPIO | 锁存器与外部输入分开；普通读和 RMW 区分；MOVX 地址使用 P2 锁存值 | 已有测试与位观察点回归继续执行；不增加电气模型 |
| 中断、RETI、idle | 已有固定同级顺序、高级嵌套、RET 不释放、RETI/IE/IP 延迟、外部电平与边沿、timer idle 唤醒 | 通过独立 ASM 程序增加真实 UART TI 唤醒、ISR 清标志和 RETI 返回验证 |
| UART TI/RI | 原 TI 与 TX 完整帧输出同时产生；RI、REN、SM2 和帧队列已有测试 | **确认并修复异步模式 TI 晚一停止位**；验证 RI/TI 独立、清除 TI 后不重发、队列和快照恢复 |

核对不等于所有硬件时序均正确。输入是离散事件/帧，外部计数边沿在 API 调用时采集，UART 接收队列在 RI 未清除时等待，保留现有教学模型。没有声称实现晶振相位、RXD 16 倍采样、硅片级中断延迟或物理接收溢出。RX 帧结束/SM2/RB8 的更细硬件相位不在此次 TI 修复内。

## 可复现缺陷和修复

原实现只在完整 TX 帧结束时置 TI。新增精确 NOP 机器周期测试在基线得到 **7 组中 6 组失败**：模式 1/2/3 的 SMOD=0/1 都晚，模式 0 正常。根据 SCON 的 TI 定义，模式 0 在第八位结束置位，异步模式在停止位开始置位。

本模型从帧启动时的 progress=0 推进；Timer1 模式 2、TH1=TL1=FF，每机器周期溢出一次：

| UART 模式 | SMOD | TI 首次可见周期 | TX 字节完整输出周期 |
| --- | --- | --- | --- |
| 0 | 任意 | 8 | 8 |
| 1 | 0 / 1 | 288 / 144 | 320 / 160 |
| 2 | 0 / 1 | 54 / 27 | 59 / 30 |
| 3 | 0 / 1 | 320 / 160 | 352 / 176 |

模式 2 用振荡周期累计并向上取整到机器周期；表为当前抽象的验收值，不是含写 SBUF 同步相位的硅片时序承诺。TX 完整输出与 txBusy 结束仍在停止位结束，ISR 可在此前执行。接收路径和默认无活动串口的执行路径不变；仅活动发送帧增加常数判断，无额外定时任务或默认事件日志。

每个 TX 帧增加可选布尔字段 `tiRaised`，保存本帧已发出 TI 的事实，避免软件清 TI 后在停止位结束再次置位。CPU v2/工作区 v4 保持不变，旧帧没有该字段仍可恢复：如已在停止位内，下一次时钟推进补发原本延迟的 TI 一次；恢复本身不修改 SCON。新快照在停止位内保存并恢复已清 TI 的状态不会重发。错误类型的字段原子拒绝；复位丢弃帧。切换模式/SMOD 的精确位相位仍不作硬件保证。

## 独立程序与回归

[uart-ti-idle.asm](../tests/fixtures/peripherals/uart-ti-idle.asm) 可直接导入 ASM 工作台构建。它让 T1 产生波特率、T0 计时，写 SBUF 后进入 idle。串口 ISR 记录 TL0 到 DATA 30h，清 TI，增加 DATA 31h，再 RETI；主程序返回后在 DATA 32h 写 55h。运行 450 个执行单元后，30h–32h 应为 `23 01 55`，TX 仅输出 `41`。本程序不依赖外部输入或 SDCC，适合定位周期差异。

核心测试检查全部模式/速率边界、队列、旧新快照、复位、RI/TI 独立和独立程序；Worker 与浏览器在 ISR 入口暂停，确认 TX 尚未完成，清 TI 后保存/刷新，再运行验证 ISR 没有重复进入。现有全量定时器、优先级嵌套、GPIO、ASM/SDCC、调试器回归纳入最终聚合检查。
