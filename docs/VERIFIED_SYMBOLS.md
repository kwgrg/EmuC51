# 可信符号浏览与只读观察

符号必须来自当前成功构建并通过绑定校验的产物；不是从裸 BIN 猜测的变量表。没有通用 C 类型系统、函数调用求值、写变量、指针解引用或无限展开。

## ASM CODE 标签

汇编器第一遍记录真实冒号标签的名字、定义行/列和 CODE 地址，仅在第二遍全部编码成功后返回。沿用大小写不敏感及重复/保留名拒绝规则；展示规范化大写名称 `ASM::<文件名>::<标签>`。EQU 与预置寄存器/SFR 常量不属于 CODE 标签。

界面区分指令起始、DB/DW 数据、指令操作数字节、未生成字节；分类使用真实输出映射和写入覆盖，不能把 ORG 空隙当作指令。标签没有可推断的函数/对象大小，界面标明“大小未知”。

- 定位定义行可跳到纯标签所在源码页。
- 查看汇编和切换断点仅允许真实指令起始标签；断点仍为地址断点，同地址别名共享现有启停、条件和次数。
- 已生成字节可跳至 CODE 内存视图，只改变浏览位置，不修改 PC；数据和操作数字节不伪装成函数入口。未生成字节无内存/断点操作入口。
- 每页最多 50 个标签，支持有界名称筛选；源码仍按既有每页 100 行显示。

源码编辑、取消/失败、固件替换或绑定不匹配立即撤下旧标签。刷新/工作区恢复只保留源码和构建绑定，必须重新成功构建后才恢复标签；不同源码即使生成相同 BIN，也不能沿用旧定义位置。

真实汇编回归：[asm-labels.asm](../tests/fixtures/asm-labels.asm)，包括同地址别名、数据、操作数字节与 ORG 空隙，不人工构造符号产物。

## SDCC 静态全局存储子集

沿用单文件 SDCC **4.5.0 #15242 / mcs51 / small / --iram-size 128 / --debug** 导入约束，校验原始源码/IHX/CDB 三份摘要和实际固件摘要。符号从原始 CDB 重新派生，不接受工作区内另存的符号表；恢复期间校验完成前不显示可信符号。

每个 `S:` 声明保留名字、构建模块、原始作用域、level/block、声明大小、类型链、地址空间码、完整声明记录及身份完全匹配的 `L:` 地址记录。限定名为 `CDB::<构建模块>::<scope>$<name>$<level>$<block>`，大小写敏感；同名文件静态与局部对象不会合并。此限定名是符号观察入口的身份，**不是表达式 Watch 的新语法**。

`G` 为全局，`F<当前模块>` 为文件作用域；本批只观察 `0_0 / 0`、非栈、非寄存器的上述声明。CDB 构建模块不证明声明来自 .c 而非其头文件，界面明确说明此限制。只有链接记录、没有 S 声明的启动/运行库名字不会被生成为变量。没有完整链接地址的声明显示不可用，不能断言一定被优化（也可能只是 extern 声明）；完全缺失的优化后对象不凭源代码补造。

只接受固定目标已验证的 `SC`（1 字节）、`SI`（2 字节）、`SL`（4 字节）及 `DA<n>d,SC`（1–16 字节字符数组）类型链和与其一致的声明大小，S/U 均只展示原始字节。依据固定版本实际输出的空间码：

| CDB 码 | 显示空间 | 可观察范围 |
| --- | --- | --- |
| E | DATA | 低 128 字节 IRAM，整对象不得越界 |
| G | IDATA | 当前经典模型同样只有低 128 字节，80h 以上不得当成 SFR |
| F | XDATA | 0..FFFFh，整对象不得越界 |
| D | CODE | 常量存储，整对象须位于已加载固件范围 |
| I | SFR | 仅已建模的经典单字节 SFR 地址，读取锁存值 |

E/G 的访问来源仍分别显示；在当前低 128 字节模型中均映射 IRAM 存储读取。类型链、大小或地址空间无法验证，指针、结构体、位/位域、PDATA、栈、寄存器、局部（包括 local static）和函数声明都显示不可用。函数 DF 声明中的 `{2}` 不被解释成函数长度，函数入口另按下述 F/X 链接子集验证。对象超过 16 字节不做截断读取或递归展开。

“读取原始字节”按地址递增顺序显示固定采样，并标出 PC/指令数；不是实时 C 数值。可显式刷新或取消观察。SFR 使用现有无副作用锁存读取，不触发端口引脚或 SBUF 接收缓冲读取。导航转入相应内存空间，不修改 CPU 或普通 Watch 列表。普通 `ACC` 始终是寄存器，不会被同名 C 变量覆盖；用户可在独立符号入口观察该变量。

运行中禁用新的符号读取/导航；已有读数明确标为固定采样。选择与采样不持久化；离页清除选择，换固件/调试数据后旧响应通过请求编号及源数据/固件身份过滤，不能覆盖新结果。

## 限额与失败行为

沿用 CDB 256 KiB、ASCII、每条 4096 字符、最多 16384 条记录限制；符号最多 2048 个声明，UI 每页 50 个。重复完整声明身份、重复链接身份、畸形记录或不安全计数拒绝整次导入；未支持但可识别的对象保留原始元数据和不可用原因。失败导入不替换当前 CPU/工作区。

SHA-256 证明文件一致性，不是编译器数字签名。清单与文件同时被伪造不能证明为真实构建；用户仍须信任外部编译器和构建来源。

## C 函数与历史调用帧

当前只接受固定 SDCC 版本的全局/当前文件静态、顶层 `F:` 函数声明（CODE，非栈），最多 256 个。通过 `G/F<module>$name$0$0` 和 `XG/XF<module>$name$0$0` 完整身份链接起止，不用 DF 的 `{2}` 作长度，也不用相邻名字补范围。`F:` 声明的 level 为 `0_0`，函数链接为 `0`，该转换仅用于函数，依据实际 `cdbFile.c` 的 `cdbWriteFunction/cdbWriteEndFunction`。

mcs51 `genEndFunction` 在最终 RET/RETI 前发出 X 记录。解析要求起止均有本模块 L:A 记录，指令合法且完整、顺序解码能抵达末指令，以该指令最后字节作闭区间边界。缺失、重复、反向、越界、不支持或无法验证的函数记录不产生可用名字。naked/优化后的非标准结束记录不推测补齐。

调用栈仅对**真实历史机器帧的精确入口地址**增加限定名称。重复入口、别名或任何已验证函数范围重叠时显示歧义，不任意选一个；入口在函数内部、启动/运行库缺失 F 记录、中断硬件向量均明确未命名。原始入口、调用点、返回地址与 SP 保留，可导航入口反汇编，不改变 PC；不把最近 C 行当成函数定义位置。

名称描述历史 CALL 目标，不声称是当前 C 活动函数：尾调用/跳转不会新增或重命名帧。ISR 的向量 LJMP 不被猜成函数帧；现有真实中断/RET/RETI 跟踪及 Step Out 规则不变。恢复时先重新核验构建，但 CPU 快照不包含调用历史，不能靠符号恢复未知帧。更换固件/调试资料立即撤下旧名称，派生函数表不持久化。

[真实函数样本](../tests/fixtures/sdcc-frames/README.md)验证静态叶函数、嵌套、三层可重入递归、Timer0 ISR/RETI 与恢复后的部分历史；浏览器验证入口导航、跳出、重复操作、离页、刷新、移动宽度和固件替换。
