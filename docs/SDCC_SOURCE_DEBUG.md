# 外部 SDCC 源码调试（单文件）

浏览器显式导入本地 SDCC 的真实产物，显示只读 C 源码、当前 PC 的精确行记录和行断点。不是浏览器 C 编译，也不是 C 语句级 Step Into/Over/Out；运行控制仍按机器指令工作。

## 生成和导入

安装可信的原生 SDCC **4.5.0 #15242 (Linux)**，在仓库执行：

```sh
SDCC_BIN=/path/to/sdcc node scripts/build-sdcc-bundle.mjs /path/to/main.c /path/to/empty-output
```

脚本在独立临时目录实际执行 `-mmcs51 --model-small --iram-size 128 --debug`，成功后输出 `main.c`、`main.ihx`、`main.cdb`、`emuc51-sdcc.json`。输出目录必须为空，失败不会把旧产物包装成成功构建。文件名须使用 ASCII 字母/下划线开头、字母数字/下划线/连字符组成的短名称；只复制一个 .c 文件，支持所安装工具链的系统头文件，不支持工程内其他头文件或源文件。

在工作台 SDCC_SOURCE 的“导入外部 SDCC 产物”同时选择上述四个文件。所有内容只在浏览器本地处理并保存。普通固件入口仍可单独加载 IHX，但不会获得源码映射。示例可直接使用 `tests/fixtures/sdcc-counter/` 或 `sdcc-flow/` 中的四个文件。

清单绑定三个原始 UTF-8 文件的 SHA-256；解析后的完整 CODE 字节另算摘要，并与恢复的当前固件比较。**摘要只校验文件一致性，不是编译器的数字签名**：使用者必须信任本地编译器和清单生成过程。自行同时修改清单和文件不能被摘要证明为真实编译；CDB 自身也没有源码或固件摘要，不能单凭文件名声称匹配。

## CDB 子集与操作语义

- 固定版本真实最终链接 CDB；恰好一个 `M:<源文件名去扩展>` 模块。`L:C$文件$行$层级$块:十六进制地址` 及同模块 `L:A$模块$汇编行:地址` 建立精确对应；源行从 1 开始，允许该版本的 `0_0` 层级。源行地址须在 CODE 范围、有对应汇编链接记录、对应合法且完整的指令。
- S 与精确身份 L 记录已增加[有限静态全局符号观察](VERIFIED_SYMBOLS.md)，F 与完整起止链接已增加严格历史入口命名；T 元数据不展开通用类型，未验证函数不猜范围。其他模块、多源文件、其他链接记录、不完整/畸形记录拒绝导入。不是通用 CDB 全格式解析器。
- 地址可能对应多行：计数器样本 A8 同时对应第 3、4 行，均高亮。单行可能有多个地址：flow.c 第 3 行包含 A8、AA、B2，全部显示。
- 仅按 PC **精确相等**显示行，绝不向后填充范围。启动 PC=0、main 的 B0 跳转、flow 的 AB 地址均无精确映射，即使人可以从源码猜测也不填充。
- 点击行断点，为该行全部记录地址补齐断点；保留已存在地址的启用状态、条件和命中次数。若所有地址已配置，再点一次移除全部（包括共享这些地址的其他行）。部分/禁用状态由“启用 x/y”显示；无记录行不可设断点。数量超限整次拒绝。
- 运行期间禁用导入和断点修改。工作区 JSON 与本地恢复携带源码、原始产物和清单；恢复完成校验前不显示可信行注释。新固件/ASM 加载清除旧源码关联；可取消尚未完成的导入并重新选择；取消会忽略旧结果。较早异步导入和校验结果不得覆盖后来的选择。校验失败不替换当前 CPU/固件/断点。

限制：源文件最多 65,536 个 UTF-16 单元、8,192 行且 UTF-8 不超过 256 KiB；IHX/CDB 各 256 KiB；清单 8 KiB；CDB 16,384 条记录，每条 4,096 字符，最多 8,192 对映射。CODE 仍最多 64 KiB、IRAM 128 字节。工作区 JSON 上限 8 MiB，以容纳源码、调试文件及现有最大调试配置的转义体积。

提供有限静态全局对象的原始字节观察；不提供 C 编辑/编译、多文件工程、通用类型、局部/优化后变量位置、源码级步进或源码覆盖率。SDCC 的其他版本/选项与 8052/厂商扩展不在当前验证范围。

参考：[SDCC CDB 格式](https://sourceforge.net/p/sdcc/wiki/CDB%20File%20Format/)。实现以仓库中真实 4.5.0 链接样本和执行回归为准，未将旧格式说明当作全版本兼容保证。

## 从源码选择目标并查看/运行

点击某行旁的一个精确地址（多地址行必须明确选一个），用“查看目标汇编”跳到反汇编；查看不会改写 PC，重复查看不会重复压入相同历史地址，可使用反汇编的返回/跟随 PC。所选行以青色边线标记，实际 PC 行仍独立以绿色标记。

“运行至源码地址”复用机器地址运行目标，在所选地址的指令执行前停止，不增加永久断点；若 PC 已在目标则不执行额外指令。现有预算、暂停、断点和观察点仍适用；目标不可到达时可能先因其他原因停止，不会声称完成该 C 语句。运行/恢复/导入校验期间不能重复提交。取消源码选择只清除选择，不取消正在执行的 CPU；运行中应点“暂停”。

选择是临时导航状态，离开工作台、加载/导入工作区、刷新或换固件时清除，不写入 JSON/IndexedDB。没有映射的地址不可从该面板选择。浏览器 C 编译仍未实现，此流程使用已验证的外部 SDCC 构建元数据。
