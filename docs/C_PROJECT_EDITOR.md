# 混合工程文件管理与本地草稿

2026-10-13。本批独立实现同一受限 C/SDAS 工程的日常编辑流程，保持经典 8051、固定 SDCC 4.5 工具链、现有外观和生产 CSP；没有后端或源码上传。

## 文件操作

展开 C 编译面板的「工程管理与本地草稿」。从「C + SDAS 示例」开始，或显式复制已加载的受校验工程：

- 「新增工程文件」按路径后缀创建 `.c`、`.h` 或 `.asm`。新 C/头文件为空，ASM 生成与文件名匹配的 `.module` 和 CODE 区骨架。
- 「重命名当前文件」只允许保持文件类型；入口改名同步更新清单 entry。同名（忽略大小写）文件或 C/ASM 模块冲突、保留名 firmware、绝对/穿越路径等均拒绝。大小写单独改名可用，但不会改变其他文件的大小写。
- 「删除当前文件」始终确认将删除全部内容（包括未保存编辑）。入口文件和最后一个 ASM 文件禁止删除；可先选择另一个 C 入口，或新增另一个 ASM 文件。新入口必须在编译验证时确实定义 main。
- 新建/改名头文件的父目录追加到 includeDirs；空目录从清单移除，已有目录搜索顺序保留。目录和文件数量继续受原协议限制。
- **不自动改写 `#include`、`.module` 或符号引用**。改名会先明确确认此边界；删除也提醒检查引用。用户手动修复源码后重新编译，缺失头文件、错误模块名或未定义符号必须失败，不能使用旧产物。这允许保存修复到一半的草稿，不是通用重构器。

结构操作先在新对象中校验，成功才整体替换；失败不部分更改清单或源码。源文件最多 16 个、头文件 16 个、包含目录 8 个；每文件 64 Ki 字符/8192 行，工程文本总量 512 Ki 字符。可以删除超限的非入口文件来修复草稿；不能保存超限结果。单 C 草稿可以保存恢复，结构管理仅对既有混合协议开放。

## 保存与恢复

- 本次浏览器会话中，切换内存/外设等页面或替换固件**不会覆盖当前编辑草稿**。要复制当前固件的源码，点击「编辑已加载 C 工程」；存在编辑时先确认替换。
- 「保存本地 C/SDAS 草稿」显式保存**一个槽位**，键为 `emuc51.c-draft.v1`，仅在当前浏览器配置和当前站点 origin 的 localStorage 中。不同浏览器/域名不同步；隐私模式或清理站点数据可能丢失，不能当跨设备备份或多项目仓库。
- 保存格式为 `emuc51-c-draft` version 1，仅包含工程清单、文件路径/文本和所选文件。没有 CPU、运行状态、编译产物、诊断或自动执行指令；不改变现有 CPU/workspace 格式。
- 刷新后点击「恢复本地 C/SDAS 草稿」。恢复先验证版本、精确字段、路径/身份、数量/文本限制及 JSON UTF-8 ≤2 MiB，再确认替换有编辑的当前草稿。坏 C/ASM 或暂时缺失 include 可以保存，坏结构不能恢复。
- 恢复不编译、不加载固件、不改变当前 PC、不自动运行。新的编辑/结构变更、恢复、示例替换、取消、离开编译面板或工作区代次变化，都使旧构建及旧诊断失效。
- 写入前完成序列化与大小校验；配额/权限失败明确提示，不更新“已保存”状态，不丢当前编辑。损坏/未来版本记录恢复失败时保留原记录和当前编辑，不静默当作空草稿。
- 替换新草稿时覆盖已有本地槽位需确认；从该槽位保存的正常后续修改可直接保存。该槽位不是跨标签页协同编辑系统，多标签页同时保存仍应避免。
- 未保存编辑关闭/刷新页面时请求浏览器原生离开确认（是否显示受浏览器用户激活策略约束）。`CLEAR_LOCAL` 也清除此槽位和会话草稿；未保存内容先确认，存储删除失败不终止活动 CPU。其他旧草稿的删除可能已经完成，不宣称跨 localStorage/IndexedDB 的原子事务。

成功编译、加载后的源码仍随固件工作区保存；此独立草稿槽只在显式保存时更新，不把固件工作区自动保存误标为草稿保存。

## 实际验证

- 在真实 Chromium WASM 编译中，从内置 C/SDAS 示例新增 C 辅助函数和头文件、将入口移到 src/start.c；改名头文件和手写 ASM 后，验证引用错误与 .module 错误，手动修复，再编译/加载/运行，实际 **P1=11**。
- 验证取消删除保留未保存文本、确认删除、最后一个 ASM/入口保护、选择错误入口导致构建失败、结构变更撤下旧结果。
- 验证会话跨页保留、坏源码保存、刷新后显式恢复、恢复不修改已有 CPU、版本损坏/配额失败保留编辑，以及清除草稿被拒绝后 CPU 仍能单步。
- 核心/存储单测覆盖路径、大小写/模块冲突、限制、缺失文件、未知字段、未来版本、JSON/UTF-8 限制、配额/权限错误。

用例：`tests/core/c-project-editor.test.ts`、`tests/persistence/c-draft.test.ts`、`tests/e2e/c-project-editor.spec.ts`。复核材料见 [截图与真实浏览器记录](screenshots/c-project-editor/README.md)。本批现网访问没有重试；不把本地测试等同现网验收。

未实现：多项目槽位、独立草稿文件导入导出、跨设备同步、自动 include/符号重构、增量构建、任意库/链接选项、完整 C51/A51 方言、通用 C 局部变量或语句级步进。Firefox/WebKit、真实手机未验证。
